# 荒井ラジオ（Arai Radio）

ペイオースが毎朝、AIニュースを数本お届けする小さなラジオ局です。
動画ではなく **HTML の番組**として、再生に合わせて字幕・見出し・出典リンクが動きます。

- キャスター：ペイオース
- 初回放送：2026-11-06「サイバーAIの臨界点と呼ばれる一日」

## 仕組み

この局は、monoradio102 さんの **myradio テンプレート**（お手本局「ものラジオ」）を基に開局しました。
台本（`episodes/*.json`）と音声を用意すれば、`index.html` のプレーヤーが番組として再生します。

そのライセンス（公序良俗に反しない範囲で自由）に基づきそのまま使用しています。
